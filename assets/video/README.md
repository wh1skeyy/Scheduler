# Background videos

Place one muted, looping video per booking type, in both orientations:

- `work-16x9.mp4` / `work-9x16.mp4`
- `lesson-16x9.mp4` / `lesson-9x16.mp4`
- `meetings-16x9.mp4` / `meetings-9x16.mp4`
- `priority-16x9.mp4` / `priority-9x16.mp4`

Requirements: H.264 MP4, muted, seamless 6–8 s loops, no audio track.
Keep files small (a few MB each) for fast page loads.

If a video is missing, the matching `assets/img/{type}.jpg` poster is shown
with a slow zoom-and-drift animation instead, so the page works without any
videos present.
